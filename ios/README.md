# Manuscript на iPhone через Xcode

Для личной установки нужен Mac с Xcode, поддерживающим версию системы на телефоне,
и iPhone с iOS 17 или новее. Для подписи подойдёт обычный Apple Account с командой
Personal Team. Профиль действует 7 дней с момента выпуска.

## Первая установка

1. На Mac [скачай ZIP с GitHub](https://github.com/RoxZ13/writting-app/archive/refs/heads/main.zip),
   распакуй его и дважды щёлкни `ios/Manuscript.xcodeproj` в Finder. Если работаешь с Git,
   обнови существующую копию командой `git pull --ff-only` или скачай новую:

   ```sh
   git clone https://github.com/RoxZ13/writting-app.git
   cd writting-app
   open ios/Manuscript.xcodeproj
   ```

2. В Xcode открой **Xcode → Settings → Accounts** и добавь свой Apple Account.
   Выбери проект **Manuscript → TARGETS → Manuscript → Signing & Capabilities**,
   включи **Automatically manage signing** и выбери свою **Personal Team**.
   Если Xcode сообщает, что Bundle Identifier уже занят, задай свой
   вместо `com.roxz13.manuscript.personal`. Сохрани этот идентификатор для следующих запусков.
3. Подключи и разблокируй телефон, подтверди доверие компьютеру. Выбери телефон рядом со схемой **Manuscript** в Xcode.
   При запросе включи на телефоне **Настройки → Конфиденциальность и безопасность → Режим разработчика**,
   перезагрузи телефон и подтверди включение.
4. Нажми **Run** (⌘R). Если телефон сообщает о недоверенном разработчике,
   подтверди доверие своей подписи в **Настройки → Основные → VPN и управление устройством**, затем открой Manuscript.

## Рукописи и повторная установка

- Приложение открывает рабочую версию с GitHub Pages и хранит локальные данные отдельно от Safari.
  Перед переносом скачай свежую JSON-копию в той версии Manuscript, где видны актуальные рукописи.
  В новом приложении подключи тот же Яндекс Диск и сверь список историй и последний написанный текст.
  Если синхронизация не подтянула рукопись, используй JSON-копию через настройки Manuscript.
- Проверь создание пробной истории, повторный запуск, синхронизацию и экспорт копии в «Файлы»
  перед тем, как сделать приложение основным местом работы.
- При истечении профиля снова подключи телефон и нажми **Run** с тем же Apple Account
  и Bundle Identifier поверх установленной копии. Не удаляй приложение для обновления подписи:
  при удалении можно потерять локальные данные. Держи актуальную резервную копию.
- Обычные правки Manuscript по-прежнему приезжают с GitHub Pages. Для изменений в папке `ios/`
  сначала подтяни Git. Для первого запуска приложения нужна сеть. Автономный запуск и вход
  в Яндекс внутри приложения следует проверить на самом телефоне.
