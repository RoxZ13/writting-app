# Manuscript.

Рабочий стол автора для тех, кто пишет большие нелинейные истории и теряет нить.
Главная задача — чтобы в любой момент было видно **что я сейчас пишу, зачем, и какие маячки ещё ждут раскрытия**.

Работает в браузере и устанавливается как приложение на iPhone, iPad, Mac и Windows. Без интернета — тоже.

## Что внутри (версия 0.1)

| Экран | Зачем |
|---|---|
| **Сейчас** | «Ты остановилась здесь»: сцена, её цель, что осталось по плану, записка себе, последние абзацы — и одна кнопка «Продолжить». Сбоку — сколько маячков висит. |
| **Письмо** | Чистый лист. Над текстом — тонкая строка-**компас**: текущий пункт плана сцены («Сейчас: Том признаётся…»), галочка — и следующий. Бриф сцены (цель, план, маячки) открывается кнопкой «Бриф» и по умолчанию скрыт. Пока печатаешь — всё вокруг текста гаснет; шевельнула мышью — вернулось. |
| **План** | Главы и сцены карточками: статус, цель, прогресс плана, маячки. Перетаскивание, фильтры («Без цели», «Нужна логика»…), «Только главы». |
| **Маячки** | Карта нитей по главам: где посеян, где раскроется. 🔴 висит (раскрытие не запланировано), 🟠 пропущен? (раскрытие было раньше, чем ты сейчас пишешь, но не отмечено), 🔵 ждёт, 🟢 раскрыт. |
| **Входящие** | Всё, что записано кнопкой ✎. Разбирается потом: привязать к сцене, сделать пунктом плана или маячком. |
| **Ещё** | Импорт (.docx, .txt, вставка из Фикбука/Google Docs), экспорт (Word целиком, Фикбук по главам), синхронизация, тема, размер текста. |

**Маячок из текста:** выдели фразу → «✦ Маячок» → «где раскроется?» (можно «пока не знаю» — тогда он будет висеть красным, пока не решишь).
В сцене раскрытия выдели фразу → «◎ Раскрытие» → выбери маячок.

**Быстрая запись:** кнопка ✎ или **Ctrl/⌘ + J** из любого места. Enter — сохранить и вернуться ровно туда, где была.

**Ничего не теряется:** текст сохраняется на устройство через секунду после паузы; версии сцены можно сохранять и возвращать; если одну сцену правили на двух устройствах офлайн, второй вариант сохраняется в «Версиях», а не затирается.

## Установить на устройства

Сначала приложение нужно опубликовать (см. ниже), потом открыть ссылку:

- **iPhone / iPad** — Safari → «Поделиться» → «На экран „Домой“».
- **Mac** — Safari → Файл → «Добавить в Dock» (или Chrome → значок установки в адресной строке).
- **Windows** — Chrome или Edge → значок установки в адресной строке.

> Важно для iPhone/iPad: Safari может очищать данные сайтов, которые не открывались 7 дней. Установленное на экран «Домой» приложение этого не касается, а синхронизация хранит копию в облаке — включи её.

## Публикация (Netlify, бесплатно, работает с приватным репозиторием)

1. Зарегистрироваться на [netlify.com](https://netlify.com) через GitHub.
2. **Add new site → Import an existing project → GitHub** → выбрать `writting-app`, ветку `main`.
   Настройки сборки подтянутся сами из `netlify.toml` — просто **Deploy**.
3. Через минуту появится адрес вида `https://что-то.netlify.app` (имя можно поменять в **Site configuration → Change site name**).
4. Каждое обновление в `main` публикуется само.

## Синхронизация между устройствами (Supabase, бесплатно)

1. Зарегистрироваться на [supabase.com](https://supabase.com) → **New project**.
2. **SQL Editor → New query** → вставить содержимое [`supabase/schema.sql`](supabase/schema.sql) → **Run**.
3. **Authentication → URL Configuration → Site URL** — адрес опубликованного приложения.
   Чтобы не подтверждать почту письмом: **Authentication → Sign In / Providers → Email → Confirm email** — выключить.
4. **Project Settings → API**: скопировать **Project URL** и **anon public key**.
5. Вставить их в приложении: **Ещё → Синхронизация → Подключить**, затем «Создать аккаунт».
   На остальных устройствах — то же самое, но «Войти».
   (Или один раз записать их в Netlify: **Site configuration → Environment variables** как `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` и пересобрать — тогда вставлять вручную не придётся.)

Как это работает: всё пишется сначала на устройство, потом, когда есть сеть, отправляется в облако. Индикатор рядом с логотипом: зелёный — синхронизировано, серый — только на устройстве.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты синхронизации, импорта и экспорта
npm run build      # сборка в dist/
```

Стек: React + TypeScript + Vite, TipTap (редактор), Dexie/IndexedDB (локальное хранилище), Supabase (облако), vite-plugin-pwa (офлайн и установка).
