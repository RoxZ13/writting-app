# Прокси для чтения с Яндекс Диска

Браузер не может скачать файл синхронизации напрямую: хост загрузки Яндекса отвечает 403 и не присылает CORS-заголовки. Эта маленькая функция скачивает файл на сервере и отдаёт его приложению. Записывать она ничего не умеет.

Прокси ничего не хранит и не пишет в лог ни токен, ни содержимое файла. Токен приходит в запросе и уходит только в Яндекс.

## Как развернуть (Yandex Cloud Functions)

- Среда выполнения: Node.js 22.
- Точка входа: `index.handler`.
- Код: файл `index.js` из этой папки, зависимостей нет.
- Память: 256 МБ.
- Таймаут: 30 секунд.
- Функция должна быть публичной (доступ без авторизации в Yandex Cloud): приложение вызывает её из браузера, а доступ к Диску проверяет токен автора.
- Переменная окружения `ALLOWED_ORIGINS` — адреса приложения через запятую. По умолчанию: `https://roxz13.github.io,http://localhost:5173,http://localhost:4173`. Запросы с других адресов получают 403.
- Встроенные ограничения: тело запроса до 16 КБ, скачиваемый файл до 50 МБ, общий таймаут запроса 20 секунд. При необходимости их можно переопределить переменными `MAX_REQUEST_BYTES`, `MAX_FILE_BYTES`, `REQUEST_TIMEOUT_MS` (значения в байтах/миллисекундах).
- Лимит файла проверяется и по `Content-Length`, и во время чтения потока. Поэтому download без заголовка размера тоже не сможет бесконтрольно занять память функции.

## Подключение к приложению

Ссылку на функцию укажи в переменной репозитория `VITE_YANDEX_PROXY_URL` (GitHub → Settings → Secrets and variables → Actions → Variables) и пересобери приложение.
