# Воспроизведение диагностических тестов

Исходники сохранены с расширением .txt, чтобы обычный npm test не запускал диагностические сценарии вместе с продуктовым набором.

Для повтора создай папку `dist-manuscript-data-audit` в корне репозитория. Скопируй туда три файла из этого каталога, сняв конечное расширение .txt. Импорты рассчитаны на это расположение. Запусти команды из [протокола данных](../data.md). Браузерная проверка неполной копии добавлена отдельным тестом, её можно выполнить фильтром `--grep 'missing required'`.

Сценарии создают только вымышленные книги. Синхронизация Vitest использует in-memory FileStore. Для Playwright рекомендуется уникальный порт и `VITE_DB_NAME='manuscript-data-audit'`, чтобы сборка отключила реальные облачные подключения. Назначение проверок — воспроизвести наблюдённые дефекты, поэтому прохождение теста не означает устранение ошибки.
