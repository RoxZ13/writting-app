# Аудит Manuscript · 17 ноября 2026

Проверяемая версия — `7094233`. Два независимых аудитора Terra xhigh изучили пользовательские пути и архитектуру. Ведущий отдельно перепроверил восстановление, повреждённую копию и узкое окно с мышью. В отчёте перечислены выполненные проверки и оставшиеся границы.

## Основные результаты

- **P1. Восстановление может скрыть активную книгу.** Входящая копия переносит пометку удаления, хотя подтверждение обещает «Ничего не удаляется». Воспроизведено через обычные экспорт и импорт между двумя тестовыми профилями. Текст остаётся в таблицах.
- **P1. Неполная копия ломает открытие текста.** Поле beats не проверяется до записи. Воспроизведено через интерфейс настроек, после импорта виден «Экран не открылся».
- **P2. Узкое окно с мышью теряет доступ к плану и шрифту.** CSS и меню выбирают компактный режим по разным критериям.
- **P2. Клавиатурные действия требуют лишнего Enter.** После закрытия контекстного меню первое открытие поглощает флаг завершения жеста. Аудитор воспроизвёл путь в Chromium и WebKit.
- **Продуктовая граница.** Для приглашённого редактора рабочий клиентский путь по ссылке отсутствует. SQL-заготовка совместной работы есть в репозитории.
