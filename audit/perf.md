# Производительность на объёме

Измерено `e2e/volume.e2e.ts` (тесты «perf: 300 scenes» и «e. timings…»), продакшен-сборка через `vite preview`, пустое хранилище на каждый запуск, 2026-10-25. Порогов нет: только цифры. Три запуска подряд, по одному воркеру; в третьем запуске на машине параллельно работали другие прогоны, поэтому он показан отдельно как «медленный».

Книга «300 сцен»: 17 частей, 300 коротких сцен, 26 286 слов. Книга «реальная»: 17 частей, 110 сцен, 124 246 слов.

Как мерили: время «до доски» после перезагрузки — от начала навигации до момента, когда в DOM все карточки (desktop 300 карточек, телефон 18 секций-глав); открытие текста — смена `location.hash` до появления текста в `.ProseMirror` (опрос requestAnimationFrame внутри страницы); перетаскивание — `page.mouse` по шагам (4 шага для активации + 25 до цели), затем ожидание, пока карточка появится в целевой колонке; long tasks — PerformanceObserver('longtask'), кадры — разницы requestAnimationFrame. Память — `performance.memory.usedJSHeapSize` с флагом `--enable-precise-memory-info` (только Chromium; в WebKit её нет).

## Что видно

- **WebKit: импорт 300 сцен занимает 35–38 с против 2,5 с в Chromium** (разрыв в 14 раз). Это Playwright WebKit на Windows, не настоящий Safari, но разрыв слишком велик, чтобы его игнорировать. Импорт — длинная серия записей в IndexedDB (`createScene` на каждую сцену). Нужно проверить на настоящем iPhone, лучше с файлом на 124k слов.
- На телефоне с замедлением CPU в 4 раза импорт 300 сцен занимает около 11 с (25 с в медленном запуске); на экране приветствия при этом только «Раскладываю текст по главам…», без прогресса.
- При первом открытии проекта срабатывают однократные `tidyImportedScenes` / `recountWords` / `recountChars`: они читают тексты всех сцен. Это видно как long tasks после импорта; отдельно не измерено.
- Перетаскивание на desktop при 300 карточках: p95 кадра 17–33 мс, один кадр ~83–117 мс при подъёме карточки.
- Список на телефоне рендерит только открытую главу; «развернуть всё» дороже всего: на x4 один кадр 217–450 мс.
- Шум машины сильно влияет: медленный запуск в 1,5–3 раза хуже обычного. Для сравнения «до/после» запускать `--workers=1` в тихий момент и брать минимум.

## Как воспроизвести

```
E2E_DIST=dist-a11y E2E_PORT=4183 npx playwright test e2e/volume.e2e.ts --workers=1
```

Каждая запись пишется строкой `PERF {...}` в консоль и в `%TEMP%\manuscript-perf.jsonl` (или в файл из `PERF_OUT`).
