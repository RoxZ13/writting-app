### 4. Импорт — крайние случаи (на рукописи не проявились)

- U+200B рядом с `===== Часть N =====` или `***` ломает разбиение на главы и сцены: `trim()` его не убирает. В рукописи 8 строк с U+200B, ни одна не на заголовке.
- Текст до первого заголовка уходит в «О книге», а не в сцены. Пролог без заголовка пропадёт из рукописи.
- Строка прозы «Часть пятая его души…» станет заголовком главы: у шаблона нет конца строки.
